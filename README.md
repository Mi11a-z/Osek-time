# Osek-time
сайт - сплетни Казахстана 

Веб-приложение в стиле Threads / X (Twitter) для публикации отзывов и коротких постов. Приложение поддерживает **режим анонимной публикации**, позволяя пользователям выбирать, делиться мнением от своего имени или анонимно. Проект разрабатывается в рамках 7-недельного учебного спринта с использованием чистого HTML, CSS и JavaScript.

## 🗄 Структура данных (JSON / LocalStorage)

1. **User (Пользователь)**
   * `id`: уникальный номер / строка
   * `username`: имя пользователя
   * `password`: пароль

2. **Post / Review (Отзыв)**
   * `id`: уникальный номер поста
   * `userId`: ID автора отзыва (сохраняется для проверки прав на удаление)
   * `content`: текст отзыва
   * `isAnonymous`: `true` / `false` (флаг анонимной публикации)
   * `createdAt`: дата и время создания
